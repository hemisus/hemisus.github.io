### 행렬의 행벡터, 열벡터

<img src="/assets/img/linear-algebra/1/Pasted%20image%2020260521115619.png" width="450"><br>

행렬에서 **행(Row)**은 가로줄, **열(Column)**은 세로줄을 의미한다.<br>
**행벡터(Row Vector = Row Matrix)**는 **하나의 행으로 이루어진 $1 \times n$ 행렬**을 의미하고,<br>
**열벡터(Column Vector = Column Matrix)**는 **하나의 열로 이루어진 $m \times 1$ 행렬**을 의미한다.

### 행렬의 곱셈

- **곱셈 조건:** 앞 행렬($A$)의 열의 수와 뒤 행렬($B$)의 행의 수가 일치해야 곱 $AB$가 정의된다.
- **교환법칙 불성립:** 일반적으로 $AB \neq BA$이다. 단, $A = pB + qE$ 또는 $B = pA + qE$ 꼴(한 행렬이 다른 행렬과 단위행렬의 선형결합으로 표현되는 경우)이면 $AB = BA$가 성립한다.
- **결합법칙:** 연산 순서가 동일하면 성립한다.
$$(AB)C = A(BC)$$
- **분배법칙:**
$$A(B+C) = AB + AC, \qquad (A+B)C = AC + BC$$

### 2×2 케일리-해밀턴 정리

![](/assets/img/linear-algebra/1/Pasted%20image%2020260521121121.png)

$$A^2 - (\operatorname{tr}A)\,A + (\det A)\,E = O$$

(단, $\operatorname{tr}A$는 대각합, $\det A$는 행렬식, $E$는 단위행렬, $O$는 영행렬)

### 대각행렬, 삼각행렬

![](/assets/img/linear-algebra/1/Pasted%20image%2020260521121226.png)

- $A$, $B$가 **둘 다 상삼각행렬**이면 → $AB$도 **상삼각행렬**
- $A$, $B$가 **둘 다 하삼각행렬**이면 → $AB$도 **하삼각행렬**
- 대각행렬끼리는 항상 교환법칙 성립: $D_1 D_2 = D_2 D_1$

### 전치행렬, 대칭행렬

<img src="/assets/img/linear-algebra/1/Pasted%20image%2020260521121300.png" style="width:500px"><br>

**전치행렬(Transpose):** 행렬 $A$의 행과 열을 서로 바꾼 행렬을 $A^T$라 한다.

- $(A^T)^T = A$
- $(A+B)^T = A^T + B^T $
- $(kA)^T = kA^T \quad (k\text{는 스칼라})$
- $(AB)^T = B^T A^T$ , $(ABC)^T = C^T B^T A^T $
- $\det(A^T) = \det(A)$
- $(A^{-1})^T = (A^T)^{-1} \quad (A\text{가 가역행렬일 때})$


**대칭행렬(Symmetric Matrix):** $A^T = A$를 만족하는 정사각행렬.<br>
**반대칭행렬(Skew-symmetric Matrix):** $A^T = -A$를 만족하는 정사각행렬.

- $A,\,B$가 대칭행렬이면 $A+B,\ A-B,\ kA$도 대칭행렬
- $A$가 대칭행렬이면 $A^n\ (n=1,2,3,\dots)$도 대칭행렬
- $A$가 가역인 대칭행렬이면 $A^{-1}$도 대칭행렬
- $A,\,B$가 대칭행렬일 때, $AB$가 대칭행렬 $\iff AB = BA$
- 임의의 정사각행렬 $A$에 대해 $A+A^T$는 대칭행렬, $A-A^T$는 반대칭행렬
- 모든 정사각행렬은 대칭행렬과 반대칭행렬의 합으로 유일하게 분해됨: $A = \tfrac{1}{2}(A+A^T) + \tfrac{1}{2}(A-A^T)$
- 정사각행렬이 아니어도, 임의의 행렬 $A$에 대해 $A^TA,\ AA^T$는 항상 대칭행렬
